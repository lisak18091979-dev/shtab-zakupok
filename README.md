# Штаб закупок

Рабочий инструмент закупщика и собственника для кризисного периода. Принцип: сначала стабилизация, потом улучшения.

## Что внутри
- Режим «Закупщику»: светофор поставок (запас считается из остатка и расхода), стресс тест, 72 часа, план на 30 дней, команда, фразы для разговоров, журнал, сводка.
- Режим «Собственнику»: панель, три цифры, решения, сводка.
- Выгрузка в Excel и скачивание страницы одним файлом.

## Как пользоваться
Откройте docs/index.html в браузере или страницу GitHub Pages. Инструмент стартует пустым: готовых цифр в нём нет, всё вносите вы или вставляете из Excel. Данные хранятся только в вашем браузере и никуда не отправляются.

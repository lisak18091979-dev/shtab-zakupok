# Штаб закупок

Инструмент для работы закупщика и руководителя: светофор поставок, стресс-тест, план 72 часа и 30 дней, нагрузка команды, журнал и утренняя сводка.

## Запуск
Откройте [готовую страницу](https://lisak18091979-dev.github.io/shtab-zakupok/) или скачайте docs/index.html.

## Учебный пример
Кнопка «Загрузить пример» включает отдельный демонстрационный набор. Все значения в нём вымышлены, они не являются сведениями ЧКПЗ или другого предприятия, не отражают рыночные цены и не являются прогнозом. Ваши данные остаются сохранёнными отдельно. Кнопка «Вернуться к моим данным» восстанавливает их.

## Данные
Без учебного режима инструмент стартует пустым. Записи хранятся в локальном хранилище браузера, не отправляются на сервер. Стресс-тест является сценарием и зависит от введённых значений; проверьте исходные данные с производством и финансами.

Исходный код доступен в каталоге src. Для пересборки: npm install, затем npm run build.
